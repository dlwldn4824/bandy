# BANDY 프로토타입 (`/app`)

11/1 동아리 회의에서 정한 12월 전 필수 기능을 화면으로 확인하는 프로토타입입니다. **DB는 아직 연결하지 않았습니다.** 데이터는 브라우저(localStorage)에만 저장됩니다.

```bash
npm run dev        # http://localhost:5173/app
```

기존 단일 공연 앱(`/login`, `/manage` 등)은 그대로 두고, `/app` 아래에서 Firebase·분석 연결 없이 따로 돕니다.

## 화면 (피그마 「Bandy 디자인」 기준)

구조는 피그마 **와이어프레임 v3**(로그인·홈·하단 바)와 **UX plan**(정보구조도, 관객·운영자 흐름)을, 색·카드·아이콘은 피그마 **모바일 화면**(공연 찾기·공연 상세·사전 예매·당일 홈)을 따랐습니다. 아이콘은 피그마에서 내려받은 SVG(`icons/`)입니다.

| 하단 바 | 내용 |
|---|---|
| 홈 | 로고·(동아리 회원은 동아리명)·알림 / 검색 / 홍보 배너(1/3) / 실시간 공연 소식 → 전체 보기 |
| 지도·캘린더 | 상단 탭 [지도][캘린더]. 지도는 카카오 연결 전 임시 지도 |
| 가운데 원형 | 개인 회원: **내 티켓**(입금 대기 → 입장 예정 → 이후 공연 → 사용 완료, 누르면 QR) / 동아리 회원: **+ 공연 등록** → 메뉴(공연 등록, 동아리 등록·수정) |
| 동아리 찾기 | 와이어프레임에선 '보류'였지만 11/1 회의에서 12월 전 필수로 올라가 넣음. 장르·지역 필터 + 교류 신청함 |
| 마이페이지 | 개인: 프로필·예매 내역·알림 / 동아리: 내 동아리(등록 공연·공연 관리·예매자 관리) / 운영자: 동아리 승인 |

그 밖에: 공연 찾기 전체 목록(`/app/events`), 공연 상세(`/app/e/:id`), 예매(`/app/e/:id/book` → 계좌 안내), 동아리 프로필·교류 신청(`/app/c/:id`), 동아리 등록(`/app/clubs/new`), 동아리 관리 — 예매자 명단·입금 확인·새 공연·프로필(`/app/manage/:clubId`), QR 입장 스캔(`/app/scan/:eventId`).

로그인은 와이어프레임처럼 개인/동아리 회원을 고른 뒤, 실제 인증 대신 시연 역할로 들어갑니다.

### 피그마와 다르게 둔 것

- **연락처 입력 없음:** 피그마 「사전 예매」에는 연락처가 있지만 노션 DB 초안에 연락처 컬럼이 없고 개인정보 수집 범위가 미정이라 입금자명만 받습니다.
- **타임라인 미리보기 없음:** 노션 DB에 공연 타임라인 테이블이 없습니다.
- **로그인 방식:** 와이어프레임은 이메일·비밀번호, 10/7 설계는 카카오입니다. 정해질 때까지 역할 선택으로 둡니다.
- **임박 티켓 1장이면 바로 QR**(와이어프레임 '제안'): 넣지 않았습니다. 입장 예정 기준은 공연 시작 24시간 전으로 임시 설정.
- **글꼴:** 가격 숫자에 쓰인 Space Grotesk는 넣지 않고 Pretendard로 통일했습니다.
- **포스터:** 시연 데이터 포스터는 저장소에 있던 기존 공연 이미지를 썼습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `types.ts` | 노션 SQL 기준 13개 테이블과 같은 필드 이름. `[11/1 추가]` 표시는 새 migration이 필요한 항목, `[확인 필요]`는 노션 캡처에서 못 본 상태값 |
| `repo.ts` | 데이터 규칙. 함수 하나가 Supabase DB 함수(RPC) 하나에 대응 (예매, 입금 확인, QR 입장, 교류 신청·응답, 동아리 등록·승인) |
| `seed.ts` | 시연용 가상 데이터 |
| `store.tsx` | 화면 상태, localStorage 저장 |
| `pages/*` | 화면 |

## Supabase로 바꿀 때

`repo.ts`의 함수 본문을 `supabase.rpc(...)`와 `select`로 바꾸고, `store.tsx`의 `run`을 비동기로 바꿉니다. 화면은 `types.ts`의 필드 이름을 그대로 쓰므로 크게 고칠 필요가 없습니다.

## 임시로 정한 값 (팀 결정 필요)

- 입금 대기 3일, 1회 최대 10장 (`repo.ts` 상단)
- 무료 행사는 입금 확인 없이 바로 확정
- 입금 확인 후 취소·환불 없음
- 서비스 이름 `BANDY` (`components.tsx`의 `APP_NAME` 한 곳만 바꾸면 됨)

## 1. 권한 — 뿌리 하나, 제일 큽니다

**B1 · B3 · B4 · B5 · M3 · M4 · M7 · M16** 과 작은 것 하나가 전부 여기서 나옵니다.

### 지금

```
membership.ts:63   export function setMembership(next)   ← 정의
S14Me.tsx:244      setMembership(null)                   ← 「나가기」. 호출은 이것뿐
routes.tsx         ManagerOnly 15군데
```

소속을 **주는** 호출이 앱 전체에 없습니다. 동아리로 가입하면 영구히 관객이고,
운영 화면 일곱 개가 닫힙니다. 게이트는 「마이에서 권한을 바꾸세요」라고 하는데
마이에 바꿀 수단이 없습니다. 반대로 데모용 기본값 탓에 **가입 직후에는 관객도
멜로딕 운영진으로 보입니다.**

권한의 **종류가 하나**인 것도 같은 뿌리입니다. 「동아리 운영진」뿐이라
공연장은 자기 수락·정산을 못 하고, `/ui/venue` 에는 게이트가 없어
**관객이 알림 한 줄로 남의 공연장 운영 화면에 들어갑니다**(거절·공개 내리기 포함).

### 고칠 것

1. `auth/membership.ts` 에 **`kind: 'club' | 'venue'`** 와 역할을 넣습니다.
2. 소속을 **주는 길**을 하나 만듭니다. 승인이 떨어지면 거기서 `setMembership` 을 부릅니다.
3. **데모 폴백을 분리합니다.** 가입 이력이 없는 기기에서만 데모를 쓰고,
   세션이 있으면 실제 소속만 따릅니다 — 알림에서 이미 쓴 규칙과 같습니다.
4. `ManagerOnly` 를 **`AllowedOnly({ need })`** 로 일반화하고, `routes.tsx` 의
   `/ui/venue` 를 공연장 권한으로 감쌉니다.
5. `S8Notifications.tsx:18` 의 `venue: P.venue` 는 공연장인 사람에게만. 관객에게는
   그 공연장의 공연 상세로 보냅니다.
6. 공연장의 입금·정산은 **별도 화면**이 필요합니다 — `S11Deposits`·`S13Settlement`
   는 동아리 기준으로 쓰여 있습니다.

> B1 을 고치는 순간 지금은 0명인 버그 하나가 드러납니다. 부원이 「다음 공연」
> (`L2Clubs.tsx:85`)을 누르면 운영진 게이트에 막힙니다. 부원도 보는 줄이니
> `P.show(...)` 로 보내고 운영진에게만 `P.run` 을 둬야 합니다.

## 3. 돈 화면이 사실과 다릅니다

**M5 · M5b · M11** 과 0번의 기한·계좌.

- **M5** 「예매 취소」에 `onClick` 이 없습니다 (`D3Deposit.tsx:152`). 2,636명이 누릅니다.
- **M5b** 「입금했어요」를 누르면 **확인 전인데 「입금 확인됨」 티켓이 바로** 나옵니다.
- **M11** 입금 대기 티켓에서도 「예매 완료」와 입장 코드가 열립니다.

셋 다 **티켓 상태가 입금 확인과 묶여 있지 않아서** 생깁니다. 상태를
`대기 → 확인됨 → 입장함` 으로 두고 화면이 거기서만 읽게 하면 같이 사라집니다.
확인은 운영진이 누르는 것이지 관객이 누르는 것이 아닙니다.

취소 버튼은 **동작을 붙이거나 지우거나** 둘 중 하나여야 합니다. 돈을 보내는
화면에서 안 눌리는 버튼은 고장으로 읽힙니다.

### 집행부 교체 — 4번에 같이 들어가야 합니다

4학년이 졸업하면 그 계정이 유일한 운영진인 동아리는 잠깁니다. 매년 일어납니다.

- 운영진이 한 명이면 콘솔에 **「한 명 더 올려 두세요」** 를 계속 띄웁니다 (막지는 않음)
- **마지막 운영진은 그냥 못 나갑니다** — 「넘기고 나가기」로 바뀝니다
- 1년 동안 아무도 안 들어온 동아리에 **「아직 쓰시나요」** 를 한 번 묻습니다

## 적어 두는 것

이 계획은 **시뮬레이션 결과를 옮긴 것**입니다. 34건 중 눈으로 확인한 것과 모델이
짚기만 한 것이 섞여 있고, 보고서에 건마다 갈라 적혀 있습니다. 「모델 추정」으로 적힌
것은 고치기 전에 화면에서 한 번 더 봐야 합니다.

사람 수는 **모델 안의 5,000명 기준**이지 실제 사용자가 아닙니다. 어느 쪽이 더
많은 사람을 막는지 견주는 데만 씁니다.
